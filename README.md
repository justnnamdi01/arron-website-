# Architecture Studio Website

A professional architecture studio website built with Next.js 15, React 19, and TypeScript.

## Features

- **Modern Design**: Clean, professional interface with smooth animations
- **Parallax Effects**: Engaging scroll-based visual experiences  
- **Project Showcase**: Interactive project slideshow and floor plan sections
- **Video Integration**: Professional video showcases
- **Client Reviews**: Dynamic testimonials section
- **FAQ Section**: Comprehensive frequently asked questions
- **Contact Forms**: Professional inquiry and consultation forms
- **Admin Dashboard**: Client data management and chat conversations
- **Chat System**: Interactive client communication
- **Responsive Design**: Optimized for all devices
- **Performance Optimized**: Fast loading with Next.js optimizations

## Technology Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS
- **Images**: Next.js Image optimization
- **Animations**: CSS transforms and transitions
- **State Management**: React hooks
- **Package Manager**: pnpm

## Deployment

This website is optimized for hosting on Hostinger and other modern web hosting platforms.
