## 🔧 **HOSTINGER UPLOAD STEPS**

### **1. Access Hostinger File Manager**
- Login to your **Hostinger hPanel**
- Click **"File Manager"**
- Navigate to **`public_html`** folder

### **2. Clean Existing Files (If Any)**
- Delete any existing files in `public_html`
- Keep only essential hosting files (`.htaccess` if present)

### **3. Upload Your Website**
**Option A: Drag & Drop Upload**
- Select ALL files from `/out` folder on your computer
- Drag them into the `public_html` folder in File Manager
- Wait for upload completion

**Option B: Zip Upload (Faster)**
- Zip the contents of `/out` folder
- Upload the zip file to `public_html`
- Extract it in File Manager
- Delete the zip file after extraction

## 🛠 **TROUBLESHOOTING**

### **Common Issues & Solutions:**

**"Images not loading"**
- Verify all folders uploaded correctly
- Check file permissions (folders: 755, files: 644)
- Clear browser cache

**"Admin dashboard not accessible"**
- Ensure `admin/index.html` exists
- Check URL: `yourdomain.com/admin` (not `/admin/`)
- Try clearing browser cache

**"Site loads slowly"**
- Enable Gzip compression in hPanel
- Use Hostinger's CDN if available
- Check image optimization

**"Mobile version issues"**
- Test on multiple devices
- Check responsive design in browser dev tools
- Verify touch interactions work
