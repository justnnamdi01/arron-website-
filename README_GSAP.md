## 🔧 Quick Customization

### Change Animation Speed
```tsx
// In the component
scrollTrigger: {
  scrub: 0.5  // Faster (default is 1)
  // or
  scrub: 2    // Slower
}
```

### Update Content
```tsx
const sections = [
  {
    title: "YOUR TITLE",
    subtitle: "Your Subtitle",
    description: "Your description...",
  },
]
```

backgroundImage: `url('/your-image.jpg')`
